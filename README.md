# Collimator VCurve — downloads

Official builds of **Collimator VCurve** (2olhares), the V-curve
metrology app for double-pass collimator benches.

- Grab the latest version under **Releases** (right side of this page):
  Windows `.exe`, macOS `.dmg`, Linux binary.
- The app checks this repository on startup and offers new versions
  automatically.
- Bugs & suggestions: use **? → SEND REPORT** inside the app, or write
  to lucas@2olhares.com.

Source code lives in a private repository; this one only hosts releases.
